Minecraft Potion Tutorial Guide.

Site name

Minecraft Potion Tutorial Guide is honestly a good enough name just for this situation. I'm not trying to sell or promote something. Just something more informational so I don't really need to be super eye catchy. possible domain: potion-guide-by-starcore.com

Site purpose

The site is for helping players set up and make potions. I probably will mention steps that people can take to set up brewing ranging from netherless to early as possible. I'll also give a expected time durations based on how many brewing stands and what automation they could take to help with automating potions. I can use my copy of minecraft to take screenshots so other people can see what I'm talking about.

Scenarios

  • How do I make a certain potion.
  • How do I set up a brewing set up.
  • How much resources will it take for a certain item.
