Lossless is compression used without damaging the original image.
lossy compression is willing to nuke pixels permenatly for even smaller files.

transparency is an Alpha channel to allow images to have something behind go through.

PNG/JPEG/GIF all have poorer performance compared to newer formats but in return supports better browser supports for older versions.
